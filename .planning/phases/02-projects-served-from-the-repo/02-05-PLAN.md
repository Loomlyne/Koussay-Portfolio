<interfaces>
Content module (no imports, no @/ alias; Node scripts import these):
  export default {
    slug, name, updated (ISO string = snapshot updatedAt), type, kind: null, client: null, industry: null, location: null,
    year, role: null, services: [], status: null, liveUrl (string or null),
    summary, overview, challenge, approach: null, outcome, tools: [...],
    testimonial: null, identity: null,
    gallery: [{ media: "brand-guideline-p01", alt: "<rendered alt>", kind: "identity", caption: null }, ...]
  }
Multi-paragraph copy: use template literals only if the live string has no backtick or "${"; otherwise a double-quoted string with \n. The value must equal the live string exactly.

Validator rules (02-RESEARCH.md Pattern 2, with D-12 overview and D-13 identity):
  SCHEMA_KEYS = slug, name, updated, type, kind, client, industry, location, year, role, services, status, liveUrl, summary, overview, challenge, approach, outcome, tools, testimonial, identity, gallery
  GALLERY_KEYS = media, alt, kind, caption
  presence: Object.hasOwn; empty (null, "", []) allowed, missing key not
  types: strings or null for text fields; services/tools/gallery arrays; kind ∈ {null,"client","own"}; status ∈ {null,"live","pre-launch"}; gallery kind ∈ {null,"screenshot","generated","identity","video"}; testimonial null or {quote,author,role}; identity null or object; updated non-empty and Date-parsable; slug matches /^[a-z0-9]+(-[a-z0-9]+)*$/; liveUrl null or https URL
  media: manifest.projects[slug].cover exists with url starting https://media.koussay.online/projects/; every gallery[i].media exists in manifest.projects[slug].gallery with the same prefix; slugs unique; 1 ≤ count ≤ maxPlanes; every manifest slug is in the list and every list slug is in the manifest
  errors: collect all, then throw one Error whose message is the lines joined by "\n", each line "[content] <slug>.<field>: <reason>" (gallery: "[content] <slug>.gallery[3].media \"x\": not in content/media.json")

resolveContent returns records in today's shape (so the UI barely changes):
  { slug, name, type, year, liveUrl, updatedAt: updated, file: cover.url, kind, client, industry, location, role, services, status,
    detail: { summary, overview, challenge, approach, outcome, tools, testimonial, identity,
              gallery: [{ file: entry.url, alt, kind, caption, width, height }] } }

MAX_PLANES lives in components/shaders/planeShaders.js (ESM; scripts import it by file URL as the old generator did with pathToFileURL(join(root, ...)).href).
