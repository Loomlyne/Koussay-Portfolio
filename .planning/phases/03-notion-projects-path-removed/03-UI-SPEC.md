# Phase 3 — UI Design Contract

> Visual contract for the one visible surface in this phase: the social share images (Open Graph and Twitter, 1200×630). No page layout, component or interaction changes. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope:** 8 project share images + 1 home share image (rendered by `scripts/media.mjs share`), 1 booking share image (static PNG, unchanged look). Locked decisions D-01..D-07 in `03-CONTEXT.md` govern; this file adds only the numbers the renderer needs.

**Numbers below were measured, not guessed:** a read-only probe in `/tmp/ogspec` (outside the repo; no R2 write, no `content/media.json` write, no `.env.local` read) fetched all eight live covers, measured luminance and rendered every card with these exact values. Results are in "Measured evidence".

## Canvas and Safe Area

| Property | Value |
|----------|-------|
| Canvas | 1200 × 630 px (1.905:1) |
| Cover crop | `sharp.resize(1200, 630, { fit: "cover", position: "centre" })` after `.rotate()` — identical to today's `lib/og-image.js` |
| Left margin (text x origin) | 64 px |
| Bottom margin (line 2 baseline) | 64 px → baseline at y = 566 |
| Right margin | 64 px → max text width 1072 px |
| Line 1 baseline | y = 506 (60 px above line 2 baseline) |

Why 64: X on some clients crops to 2:1 (≈15 px off top and bottom), iMessage and LinkedIn round corners (≈12–16 px). 64 px clears both with room; line 2 descenders end at ≈ y 573, 57 px above the edge.

**Square crop (accepted loss):** WhatsApp's small thumbnail and Slack/Telegram compact previews centre-crop to 630 × 630 (x 285–915). Bottom-left text at x 64 falls outside that crop by design of D-01. In those views the cover alone shows and the page's `og:title` text beside it carries the name. The D-07 preview shows this crop so Koussay sees it before signing.

## Spacing Scale

Share-image placements, all multiples of 4:

| Token | Value | Usage |
|-------|-------|-------|
| margin | 64px | Left, right and bottom inset of the text block |
| baseline-gap | 60px | Line 1 baseline to line 2 baseline |
| shrink-step | 4px | Font-size decrement when a line exceeds 1072 px |

Page spacing tokens: not applicable (no page UI change).

Exceptions: `baseline-gap 60px` is a typographic line height (0.83 × the 72 px name size), not a layout gap.

## Typography

| Role | Font file | Size | Weight | Tracking | Colour |
|------|-----------|------|--------|----------|--------|
| Line 1 (name) | Geist-Medium.ttf | 72 px (shrinks, see rule) | 500 | −0.02 em (−1.44 px at 72) between glyphs, none after the last | `#FFFFFF`, opacity 1 |
| Line 2 (type · name / tagline) | Geist-Regular.ttf | 32 px (shrinks, see rule) | 400 | 0 | `#FFFFFF`, `fill-opacity` 0.85 |

- Weight 500 and −0.02 em match the ring's name labels (`components/ring/params.js`: `nameWeight: 500`, `nameTracking: -0.02`), so the card reads as the same brand as the site. Two weights only.
- Line height is fixed by baselines (506 / 566), not a ratio; 60 px baseline gap = 0.83 × the name size, which keeps the two lines one block. Descender of "y"/"j" (Almar Private Journey) clears line 2 cap height by ≈ 24 px.
- Kerning comes from `font.layout()` (GPOS). Tracking is added on top of the shaped advance.

**Long-text rule (one line, never wrap):**
1. Lay out at the default size. If width ≤ 1072 px, use it.
2. Otherwise reduce by 4 px and re-measure. Line 1 floor 56 px; line 2 floor 24 px.
3. If still wider than 1072 px at the floor, the script throws `[share] <slug>: line 1 too long at 56 px` and writes nothing. No ellipsis, no wrap.
4. If any glyph resolves to `.notdef` (`glyph.id === 0`), throw `[share] <slug>: missing glyph in "<text>"`. No substitute font.

Measured: all nine cards fit at the default sizes (widest line 1: "Almar Private Journey" 716 px; widest line 2: "Creative developer and brand designer" 564 px). The shrink rule is a guard for Phase 7 names, not used today.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | the project cover itself | Full canvas |
| Secondary (30%) | `#000000` gradient, 0 → 0.45 → 0.80 | Bottom 60% fade under the text |
| Accent (10%) | `#FFFFFF` | Line 1 text (opacity 1) and line 2 text (opacity 0.85) only |
| Booking background | `#F4F5F6` (`{ r: 244, g: 245, b: 246 }`) | Booking card only, unchanged from today |
| Destructive | not applicable | No actions on an image |

Accent reserved for: the two text lines. No rule lines, badges, logo marks or coloured separators.

**Contrast floor (build-time check is not required; D-07 check is):** white text against the shaded background, sampled in each line's glyph band, must be ≥ 4.5:1 at the band's 95th-percentile luminance. All nine cards meet it today (lowest: 4.5:1, PIXENHOUSE / home name band).
