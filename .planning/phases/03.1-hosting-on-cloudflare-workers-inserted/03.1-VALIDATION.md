## Sampling Rate

- **After every task commit:** the task's own `<automated>` command (targeted `node --test scripts/<file>.test.mjs` or `npx playwright test tests/<spec> [-g …]`), listed per task below
- **After every plan (last task of each plan = wave end):** full suite, including `npm test` on the Workers preview. Only plan-final tasks run full `npm test`; the one exception is 02 Task 2, where the smoke suite is the targeted test (it is the thing being made green)
- **Before `/gsd-verify-work`:** full suite green, `node scripts/check-worker-bundle.mjs` green, D-14 UAT signed, production curl checks
- **Max feedback latency:** 5 seconds (quick), 240 seconds (full)
