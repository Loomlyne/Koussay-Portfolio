Repo conventions that apply to every file below (from CLAUDE.md): plain JavaScript, `@/` alias in app code, env only through `lib/env.js`, bracketed log tags, `json(data, status)` helper, `export default function` for components and named exports elsewhere, Prettier defaults (`format:check` is a gate), `"use client"` first line only where hooks or browser APIs are used. New pure modules (`lib/store/sql.mjs`, `lib/mail/ics.mjs`, `lib/admin/access.mjs`) use relative imports only so `node --test` can load them (Pitfall 9).
