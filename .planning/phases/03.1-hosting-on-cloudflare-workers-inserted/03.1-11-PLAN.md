| Boundary | Description |
|----------|-------------|
| visitor-uploaded bytes -> admin browser | untrusted files rendered on the site origin |
| visitor-typed website and research sources -> links | untrusted URLs rendered as anchors |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3.1-38 | Tampering (stored XSS) | file route | mitigate | Inline allowlist only; everything else octet-stream + attachment; nosniff; CSP sandbox; tested with SVG and HTML |
| T-3.1-39 | Elevation of privilege | file route | mitigate | requireAdmin before any lookup; 403 test |
| T-3.1-40 | Information disclosure | caching | mitigate | private, no-store on page and file responses |
| T-3.1-41 | Tampering (reverse tabnabbing / javascript: URL) | Website ↗ and research sources | mitigate | websiteHref allows only http/https; rel="noopener noreferrer"; tested with a javascript: website |
| T-3.1-78 | Tampering (open redirect) | back link `from` | mitigate | `from` re-parsed through parseListParams and rebuilt with listHref; only /admin/bookings URLs result |
